# Proposal

## Why

Telegram-бот является тонким клиентом платформы Zeta для взаимодействия студентов и старост через Telegram без хранения бизнес-логики и прямого доступа к БД. Для реализации фазы Итерации 1 (задачи Z-08 и Z-09 в рамках issue #25) необходимо развернуть базовый каркас пакета `telegram-bot/` с асинхронным фреймворком `aiogram` 3.x, long polling, конфигурацией, клиентом к backend API, graceful shutdown, структурированным логированием, а также предоставить пользователю первичный онбординг по команде `/start` (с кнопками перехода в веб-интерфейс) и справку `/help`.

## What Changes

- Развёрнут каркас пакета `telegram-bot/` на базе `aiogram` 3.x и `uv` в каталоге `src/telegram_bot`.
- Реализована конфигурация через переменные окружения (`BOT_TOKEN`, `BACKEND_BASE_URL`, `POLLING_TIMEOUT`, `LOG_LEVEL` и др.) с валидацией и шаблоном `.env.example`.
- Настроен запуск бота в режиме long polling с корректным graceful shutdown (SIGINT/SIGTERM) и обработкой сетевых сбоев.
- Реализован асинхронный HTTP-клиент к FastAPI backend (`BackendClient`) с базовым URL, таймаутами и обработкой сетевых исключений.
- Реализованы хэндлеры команд `/start` и `/help`:
  - `/start` отправляет приветственное сообщение с объяснением возможностей Zeta и inline-кнопкой перехода в веб-приложение (Telegram Login Widget).
  - `/help` отправляет справку по доступным командам.
  - Обработка неизвестных сообщений и команд с подсказкой доступных действий.
- Настроены тесты (pytest, pytest-asyncio) с моками Telegram Bot API и backend-клиента, линтер ruff и тайпчекер mypy по стандартам AGENTS.md.
- Обновлён `telegram-bot/README.md` с инструкцией по локальному запуску и описанием конфигурации.

## Capabilities

### New Capabilities
- `telegram-bot/core`: Базовый рантайм Telegram-бота, конфигурация, long polling цикл с graceful shutdown, логирование и асинхронный HTTP-клиент к backend API.
- `telegram-bot/onboarding`: Пользовательский интерфейс первого контакта в Telegram: команды `/start`, `/help`, онбординг, инлайн-кнопки перехода в веб-приложение и обработка неизвестных команд.

## Impact

- Пакет `telegram-bot/` становится полностью работоспособным и верифицируемым независимым сервисом монорепозитория.
- Добавляются зависимости в `telegram-bot/pyproject.toml` (`aiogram`, `httpx`, `pydantic-settings` и dev-зависимости).
- Внешние пакеты (`backend`, `frontend`, `mobile`) не затрагиваются, контракт взаимодействия с backend остаётся в рамках существующего REST API.
