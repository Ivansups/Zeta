# Spec Delta

## Purpose

Обеспечивает первичный онбординг студентов и старост в Telegram, знакомя их с возможностями Zeta, предоставляя ссылки на веб-версию и подсказки по доступным действиям.

## ADDED Requirements

### Requirement: Welcome and Onboarding Message
По команде `/start` бот SHALL отправлять приветственное сообщение с описанием возможностей Zeta и кнопками быстрого доступа.

#### Scenario: User sends /start command
- **WHEN** пользователь отправляет команду `/start`
- **THEN** бот отвечает приветственным текстом с описанием сервиса Zeta и прикрепляет inline-кнопку перехода в веб-версию

### Requirement: Help Command
По команде `/help` бот SHALL отправлять список доступных команд и краткую справку по работе.

#### Scenario: User sends /help command
- **WHEN** пользователь отправляет команду `/help`
- **THEN** бот отвечает сообщением с перечнем доступных команд и инструкцией по использованию

### Requirement: Fallback for Unknown Input
При получении неизвестного сообщения или команды бот SHALL отправлять подсказку с доступными действиями.

#### Scenario: User sends unknown text or command
- **WHEN** пользователь отправляет нераспознанную команду или текстовое сообщение вне контекста
- **THEN** бот вежливо сообщает, что команда не распознана, и предлагает воспользоваться `/start` или `/help`
