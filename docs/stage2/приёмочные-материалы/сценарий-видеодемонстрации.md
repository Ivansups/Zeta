# Сценарий видеодемонстрации Zeta (S-19 / Пакет 9.2)

**Проект:** Система учёта домашних заданий Zeta  
**Назначение:** Резервная видеозапись демонстрации продукта (1.5–2 минуты) для защиты проекта на случай сбоев сети или недоступности внешних сервисов во время показа.  
**Формат:** 1080p, MP4, 60 fps, закадровые пояснения спикера.  
**Размещение записи:**  
- Облачный диск команды: https://disk.yandex.ru/d/zeta-demo-presentation-2026  
- Локальная копия: `docs/stage2/приёмочные-материалы/media/zeta-final-demo-1080p.mp4`

## 2. Порядок показа

1. **Основной сценарий (живой показ):**
   - Демонстрация проводится на запущенном стенде http://localhost:3000.
   - При сетевых задержках или сбоях Telegram Bot API спикер переключается на видеофайл `zeta-final-demo-1080p.mp4`.
2. **Резервный сценарий (по видеозаписи):**
   - Видео запускается локально без звука, спикер озвучивает шаги по таймкодам из таблицы.

## 3. Подготовка демонстрационного стенда

Для воспроизведения демонстрации на чистом окружении:

```bash
# 1. Запуск сервисов
docker compose up -d --build

# 2. Заполнение базы тестовыми данными
docker compose exec backend uv run python -m backend.seed

# 3. Открытие страницы входа
open http://localhost:3000/login
```

Скрипт сидинга создаёт:
- Тестовую группу с расписанием на две недели (числитель и знаменатель);
- Профили старосты и студентов обеих подгрупп;
- Набор домашних заданий с разными сроками сдачи.
