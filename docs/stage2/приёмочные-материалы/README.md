Комплект приёмочно-сдаточной документации и демонстрационных материалов проекта **Zeta** (Система учёта домашних заданий студентов ФКН) для защиты перед приёмочной комиссией и заказчиком.

**Этап:** 2 — Реализация, мониторинг и адаптация (Итерация 4).  
**Основание:** [ИСР 9.2](../../stage1/05-иерархическая-структура-работ.md), [Бэклог продукта (история S-19)](../../stage1/11-бэклог-продукта.md), [Техническое задание](../../Task.md), [Устав проекта](../../stage1/03-устав-проекта.md).

## 2. Краткий паспорт приёмки MVP

- **Наименование системы:** Zeta (Система учёта домашних заданий студентов ФКН).
- **Версия релиза MVP:** 1.0.0 (ветка `main`).
- **Стек реализации:**
  - **Backend:** Python 3.13, FastAPI, SQLAlchemy 2.0 (asyncpg), Alembic, PostgreSQL 17, `uv`.
  - **Frontend & Mini App:** Next.js 16 (App Router), TypeScript, Tailwind CSS, `@zeta/theme`, `pnpm`.
  - **Mobile:** React Native, Expo SDK 58, TypeScript, `pnpm`.
  - **Telegram Bot:** Python 3.13, aiogram 3, long polling, `uv`.
  - **Инфраструктура:** Docker Compose, Coolify 4, Traefik, GitHub Actions CI/CD.
- **Статус критериев приёмки (Issue #101):**
  - [x] Комплект слайдов презентации подготовлен, структурирован и согласован со всеми участниками команды.
  - [x] Видеодемонстрация и приёмочный акт оформлены и зафиксированы в репозитории/облачном диске.
  - [x] Инструкция по запуску верифицирована на чистом окружении через `docker compose up -d --build`.
