## 3. Расчёт показателей освоенного объёма (EVM — Earned Value Management)

Основание для плановых оценок — [Сводная таблица оценок](../../stage1/06-сводная-таблица-оценок.md) (Фаза 3):
- Общий плановый фонд трудоёмкости проекта (BAC): **552.7 чел.-ч**.
- Плановая трудоёмкость пакетов Итерации 1 (PV):
  - Пакет 3.1 (Монорепо, CI) = 6.3 ч
  - Пакет 3.2 (PostgreSQL, dev-окружение, бот) = 10.3 ч
  - Пакет 4.1 (Backend: auth) = 19.0 ч
  - Пакет 5.1 (Frontend: авторизация) = 12.7 ч
  - Пакет 6.1, 6.2 (Telegram-бот: start, long polling) = 23.0 ч
  - Пакет 7.1, 7.2 (Mobile: каркас, авторизация, расписание S-04) = 23.0 ч
  - **Итого плановый объём (PV):** **94.3 чел.-ч**

### Фактические показатели по итогам Итерации 1:
- **Освоенный объём (EV — Earned Value):**
  - Полностью закрыты пакеты 3.1, 3.2, 4.1, 5.1, 6.1, 6.2, 7.1, 7.2.
  - $EV = 6.3 + 10.3 + 19.0 + 12.7 + 23.0 + 23.0 = \mathbf{94.3\text{ чел.-ч}}$
- **Фактические трудозатраты (AC — Actual Cost):**
  - По данным списания часов в трекере суммарно командой затрачено: $\mathbf{98.0\text{ чел.-ч}}$ (Климов — 24 ч, Шелудько — 20 ч, Берестнев — 22 ч, Ремезов — 14 ч, Ульянченко — 18 ч).

### Метрики отклонений и индексы:
| Метрика | Формула | Значение | Интерпретация |
|---|---|:---:|---|
| **Отклонение по срокам (SV)** | $SV = EV - PV$ | $94.3 - 94.3 = \mathbf{0.0\text{ ч}}$ | Идём строго по графику |
| **Отклонение по стоимости (CV)** | $CV = EV - AC$ | $94.3 - 98.0 = \mathbf{-3.7\text{ ч}}$ | Незначительный перерасход часов (~4%) на отладку Expo SDK 58 |
| **Индекс выполнения сроков (SPI)** | $SPI = EV / PV$ | $94.3 / 94.3 = \mathbf{1.00}$ | План по содержанию выполнен на 100% |
| **Индекс выполнения стоимости (CPI)** | $CPI = EV / AC$ | $94.3 / 98.0 = \mathbf{0.96}$ | Эффективность затрат близка к плановой |

### Прогнозные показатели:
- **Оценка по завершении (EAC):**  
  $$EAC = \frac{BAC}{CPI} = \frac{552.7}{0.96} = \mathbf{575.7\text{ чел.-ч}}$$
- **Отклонение по завершении (VAC):**  
  $$VAC = BAC - EAC = 552.7 - 575.7 = \mathbf{-23.0\text{ чел.-ч}}$$  
  *(Покрывается заложенным в Уставе 15% буфером времени команды)*.
